# Casa Brava Rentals — Prototipo Visual

Sistema de reservaciones para casa privada. Prototipo de interfaz (Next.js + Tailwind), sin backend conectado todavía.

```bash
npm install
npm run dev
```

Abrir [http://localhost:3000](http://localhost:3000).

Para la guía de estructura de carpetas, componentes editables y datos mockeados, ver [DOCUMENTATION.md](DOCUMENTATION.md). Para las convenciones técnicas del proyecto, ver [CLAUDE.md](CLAUDE.md).
